# AI Render Tool

레퍼런스 이미지를 올리면 그 **스타일(조명·색감·재질·분위기)** 을 분석해 비슷한 느낌의 이미지를 렌더링해 주는 웹 툴입니다.
OpenAI GPT Image API(`images.edit`)로 동작합니다.

## 사용 방식

| 입력 | 필수 | 역할 |
|---|---|---|
| 베이스 이미지 | 선택 | 스케치, 3D 모델 캡처, 사진 등. **구도·형태를 그대로 유지**한 채 렌더링합니다. |
| 레퍼런스 이미지 | 필수 (최대 15장) | 따라 하고 싶은 스타일. 주제/레이아웃은 따라 하지 않고 **룩만** 가져옵니다. |
| 추가 설명 | 선택 | "노을 조명, 우드 마감 강조" 같은 추가 지시 |

- 베이스 이미지가 있으면 → 베이스의 구도 + 레퍼런스의 스타일
- 베이스 이미지가 없으면 → 레퍼런스 스타일로 새 이미지 생성 (추가 설명에 무엇을 그릴지 적어주세요)

스타일 반영 강도, 크기, 품질, 생성 개수(1~4), 모델을 고를 수 있습니다.

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
cp .env.example .env   # .env 에 OPENAI_API_KEY 입력
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 결과 이미지는 `outputs/` 폴더에도 저장됩니다.

## 설정 (.env)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | — | OpenAI API 키 |
| `OPENAI_IMAGE_MODEL` | `gpt-image-2` | 기본 모델 (`gpt-image-1.5`, `gpt-image-1`, `gpt-image-1-mini` 등) |
| `PORT` | `3000` | 서버 포트 |

## 구조

- `server.js` — Express 서버. 업로드된 이미지를 `[베이스, 레퍼런스...]` 순서로 `images.edit`에 전달하고, 각 이미지의 역할을 설명하는 프롬프트를 자동으로 구성합니다 (`buildPrompt`).
- `public/index.html` — 드래그 앤 드롭 업로드 UI, 결과 및 최근 렌더링 기록.

결과 화면의 "실제로 보낸 프롬프트"에서 모델에 전달된 전체 지시문을 확인할 수 있습니다. 결과가 마음에 들지 않으면 `server.js`의 `buildPrompt`를 수정해 프롬프트를 조정하세요.
